# Bank Customer Churn Prediction using Artificial Neural Networks (ANN)

An end-to-end Deep Learning project that predicts whether a bank customer is likely to churn (leave the bank) using an Artificial Neural Network (ANN) built with Keras/TensorFlow and deployed via FastAPI.

## Features

- **Data Preprocessing:** Standardized numerical features using `StandardScaler`.
- **Deep Learning Model:** Built a multi-layer ANN with `ReLU` hidden activations and `Dropout` regularization.
- **Binary Classification:** Used `Sigmoid` activation and `Binary Crossentropy` loss function.
- **REST API Deployment:** Implemented a real-time prediction service using `FastAPI`.
